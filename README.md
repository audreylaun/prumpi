**For MacOS users who want to use the executable** (AKA have a downloadable game file that you can open like a regular app): 
**Please follow these instructions!**

Go to the "Releases" page and open up the [most recent release](https://github.com/audreylaun/prumpi/releases/tag/2.0.0). 

Download the zip file, unzip, and open the executable. 

**You will get the following warning/error message**
<img width="267" height="250" alt="warning" src="https://github.com/user-attachments/assets/ae4e5d45-67b5-464b-86d2-b7145c74022a" />

To bypass the privacy warning and play the game, you need to go to your settings and manually allow the game to open. 
<img width="531" height="625" alt="allow" src="https://github.com/user-attachments/assets/c7bdeca8-5737-4f35-a303-d43321668df2" />

Once you input your computer's password and allow Prumpi World to open, you can go back to the executable and it should open!
